Quick start

From localhost to HTTPS in three steps

01

Run your app

Start any HTTP service on your machine.

python -m http.server 5000
02

Start the agent

Copy the generated command from your tunnel card and run it in another terminal.

python - tunnel-name 5000
03

Share the URL

Requests to your HTTPS subdomain now reach localhost.

https://tunnel-name.{{ tunnel_domain }}
Security note

Anyone with the public URL can reach the service while your agent is connected. Protect sensitive applications with their own authentication and stop the agent when sharing is finished.
